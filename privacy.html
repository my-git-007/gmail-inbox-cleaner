Privacy policy

Gmail Cleaner. Last updated November 2, 2026.

Gmail Cleaner is a personal tool used only by its owner, on their own Google account. It has no other users.

What it accesses

Gmail (gmail.modify): it reads the sender, subject, date, labels and a short preview of messages, and it adds or removes labels and moves messages to Trash. It does not send email and does not permanently delete messages.

Google Drive (drive.file): it creates and updates one review spreadsheet. It can only see files it created itself.

Where the data goes

Message details are stored only on the owner's own computer, in a local database used to make cleanup decisions. Sign-in credentials are stored in the computer's encrypted Windows Credential Manager. No data is sold, shared with third parties, or used for advertising.

The tool has an optional AI-suggestion feature, off by default. Only if the owner turns it on, sender addresses, names and subject lines (not message bodies) are sent to Anthropic's API to suggest cleanup actions.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the program's folder removes all locally stored data.
